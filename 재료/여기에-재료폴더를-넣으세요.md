# 여기에 Claude Code 데스크탑이 만든 재료 폴더를 넣습니다

한 강의가 폴더 하나입니다. 이름은 **`NNN강`으로 시작**하게 지으세요 — 120강이
쌓였을 때 정렬이 되고, 웹 화면의 '촘촘히' 보기에서 타일 라벨로 그 앞자리만
남습니다(`000강-EMR기초` → `000강`).

영상이 오기 전에 **폴더만 미리 만들어 두어도 됩니다.** 웹 화면에 빨간 점으로
`mp4 없음`이라 뜨고, 영상을 넣으면 초록으로 바뀝니다.

```
재료/
  000강-EMR기초/
    script.json          씬별 대본 (narration_ru · narration_ko · est_sec)
    subs.uz.srt          우즈벡어 자막 ← 정답지. 파이프라인에 넣지 않습니다
    slides/
      001.html … 032.html
```

넣은 다음:

```
tools\sample\run.bat "재료\000강-EMR기초"
```

이러면 같은 폴더 안에 이렇게 생깁니다.

```
    _build/
      audio/001.wav …     Piper 러시아어 합성음 (씬별)
      slides/001.png …    1920×1080으로 구운 슬라이드
      _seg/001.mp4 …      씬별 조각
      durations.json
    dummy.mp4            ← 45분 강의 영상. 이걸 본 파이프라인에 넣습니다
```

그다음 루트에서:

```
run.bat "재료\000강-EMR기초\dummy.mp4" "재료\000강-EMR기초\_build\slides"
```

## subs.uz.srt 는 왜 안 넣나

파이프라인의 s2(전사)·s3(자막 만들기)가 제대로 도는지 보려면, 정답을 화면에 띄워
놓고 시험을 보면 안 됩니다. Claude Code 데스크탑이 준 자막은 **s3 결과와 견줄
정답지**로 그 자리에 그대로 두고, 파이프라인은 오디오만 듣고 자막을 스스로
만들게 합니다. 둘을 나란히 놓고 큐 경계가 비슷한지 보는 것이 s3 검증입니다.
