## 30초 요약

강의 mp4 하나를 넣으면 **perso에 그대로 올릴 조각 패키지**가 나온다.
영상을 만들지는 않는다 — 그건 perso가 한다.

```
run.bat  →  브라우저에서 강의 고르기  →  돌리기  →  output\<작업>\06\perso\
```

perso에 가는 것은 `06\perso\` 하나뿐이다. 나머지 `00`~`05`는 중간산물이고,
문제가 생겼을 때 어디서 틀어졌는지 되짚기 위해 남겨 둔다.
