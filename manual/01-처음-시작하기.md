# 01 처음 시작하기

## 미리 있어야 하는 것

| 무엇 | 확인 | 없으면 |
|---|---|---|
| Python 3.10+ | `python --version` | https://www.python.org/downloads/ 에서 설치. **"Add python.exe to PATH" 체크** |
| ffmpeg | `ffmpeg -version` | `winget install Gyan.FFmpeg` 뒤 **새 터미널**을 연다 (PATH 갱신) |

## 설치 — 처음 한 번만

```
setup.bat
```

python·ffmpeg를 확인하고 `.venv`를 만들어 패키지를 깐다. 1~2분.

시험용 강의를 직접 만들 거라면 하나 더:

```
tools\sample\setup.bat
```

playwright(슬라이드 굽기용 크로미움)와 Piper 러시아어 음성을 받는다. 몇 분 걸린다.
**루트 `setup.bat`이 먼저다** — 이쪽은 그 `.venv`를 같이 쓴다.

## 재료 넣기

강의 하나가 폴더 하나다. `재료\` 안에 넣는다.

```
재료\
  001강\
    강의영상.mp4          ← 이것만 있으면 된다
    slides\               ← 있으면 씬 표가 더 나온다. 없어도 돈다
```

이름은 **숫자로 시작**하게 짓는다. 화면의 촘촘히 보기에서 타일 라벨이 그 숫자다.
영상이 오기 전에 폴더만 미리 만들어 두어도 된다 — 빨간 점으로 `mp4 없음`이라 뜨고,
영상을 넣으면 초록으로 바뀐다.

## 돌리기

```
run.bat
```

브라우저가 열린다. **이 검은 창은 켜 둔 채로 쓴다** — 닫으면 서버가 꺼진다.

첫 실행에서 음성인식 모델을 한 번 내려받는다(small 약 500MB / medium 약 1.5GB).
그 뒤로는 안 받는다.

## 얼마나 걸리나

35분짜리 영상 기준 실측이다.

| 단계 | 시간 |
|---|---|
| s1 영상 받기 | 45초 |
| s2 전사 (small, CPU) | 8분 — **영상 길이의 0.24배** |
| s3 자막 · s4 분할 | 몇 초 |
| s5 씬 매핑 | 33초 |
| s6 패키지 (영상 다시 인코딩) | 몇 분 |
| s7 검수본 (앞 60초) | 1분 |

**s2가 대부분이다.** 오래 멈춘 것처럼 보여도 러시아어 문장이 한 줄씩 흐르면 정상이다.
급하면 모델을 `small`로 두고 돌린 뒤, 품질이 필요할 때 `medium`으로 s2만 다시 돌린다.
