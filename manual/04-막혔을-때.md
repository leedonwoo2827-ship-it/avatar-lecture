# 04 막혔을 때 — 오류 메시지별

오류는 **어느 단계에서 멈췄는지**를 먼저 본다. 아래 기록에 `[s2] 멈췄습니다` 처럼
단계가 찍혀 있다. 고친 뒤에는 **그 단계부터** 다시 돌리면 된다 — 앞 단계는 이미
파일로 남아 있어 다시 안 해도 된다.

---

## 창이 열리자마자 닫힌다 / `Run setup.bat first.`

`.venv` 가 없다. `setup.bat` 을 먼저 돌린다.

---

## `[ERROR] No working Python 3.10+ found.`

파이썬이 없거나 PATH에 없다. https://www.python.org/downloads/ 에서 설치하되
**"Add python.exe to PATH" 를 반드시 체크**한다. 설치 뒤 새 터미널을 연다.

---

## `[ERROR] ffmpeg not found on PATH.`

```
winget install Gyan.FFmpeg
```

설치 뒤 **새 창**을 열어야 PATH가 갱신된다. 기존 창에서는 계속 안 잡힌다.

---

## `오류: 워크스페이스가 없습니다`

s1을 돌리지 않고 s2 이후를 먼저 부른 것이다. 웹 화면에서 `돌리기` 로 시작하면 순서가 맞는다.

---

## `오류: 영상 파일이 없습니다` / 타일이 빨간 점

그 폴더에 mp4가 없다. 무엇을 찾았는지만 미리 보려면:

```
.venv\Scripts\python scripts\s1_ingest.py "재료\001강" --dry-run
```

찾는 자리는 폴더 바로 아래와 한 겹 안쪽이다. `slides` · `슬라이드` · `_build\slides`
순으로 슬라이드를 찾는다.

---

## `오류: 영상이 N개입니다`

한 폴더에 mp4가 여럿이다. 하나만 남기거나 파일 경로를 직접 준다.

```
.venv\Scripts\python scripts\s1_ingest.py "재료\001강\그영상.mp4"
```

---

## s2에서 아주 오래 멈춘 것 같다

**대개 정상이다.** 35분 영상이 small 모델로 8분쯤 걸린다(영상 길이의 0.24배).
첫 실행에서는 모델도 받는다.

전사가 시작되면 인식된 문장이 한 줄씩 흐른다. **그게 안 흐른 채 몇 분 이상이면**
모델을 받는 중이다. 인터넷을 확인한다.

---

## `오류: faster-whisper가 없습니다`

`setup.bat` 을 다시 돌린다.

---

## 씬이 1개만 검출된다

슬라이드 전환이 검출 바닥값보다 작다. `--floor` 를 낮춘다.

```
.venv\Scripts\python scripts\s5_scene_map.py --floor 0.005
```

흰 배경에 글자만 바뀌는 슬라이드는 변화량이 0.05 언저리다. 실사 영상 기준으로
흔히 쓰는 0.30 은 여기서 하나도 못 잡는다.

---

## 자막 번역이 안 된다 / `claude-agent-sdk 가 없습니다`

왼쪽 아래 **`Claude 연결`** 단추를 눌러 상태를 본다. 세 가지가 다 초록이어야 한다.

| 줄 | 안 되면 |
|---|---|
| 실행 파일 | `claude` CLI 가 없다. 설치하거나 VSCode 확장을 깐다 |
| 로그인 | 패널의 `로그인` 을 눌러 콘솔에서 마친 뒤 `다시 확인` |
| 파이썬 붙임 | `setup.bat` 을 다시 돌린다 |

**API 키는 필요 없다.** `claude` CLI 로 로그인해 둔 세션을 그대로 쓴다.
환경변수에 `ANTHROPIC_API_KEY` 가 있어도 파이프라인은 일부러 무시한다 —
오래된 설정이 남의 계정에 과금되는 것을 막기 위해서다.

---

얹으면 두 겹이 된다. `지시서.md` 의 검수 기준에 그 항목이 있다.

`Ctrl+Shift+R` 로 강제 새로고침한다.

## 그래도 모르겠으면

`output\<작업>\` 폴더를 **지우지 말고** 그대로 두고 문의한다.
`00`~`05` 의 중간산물이 어디서 어긋났는지 되짚는 근거다.
