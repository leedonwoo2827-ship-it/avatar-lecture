# 02 화면 사용법

```
run.bat  →  http://127.0.0.1:6326
```

검은 창은 켜 둔 채로 쓴다. 닫으면 서버가 꺼진다.

화면은 왼쪽 **레일**(메뉴) · 가운데 **본문** · 오른쪽 **작업 현황** · 아래 **기록** 넷이다.
셋은 따로 접힌다 — 자막을 다듬을 때는 다 접고 넓게, 배치를 돌릴 때는 현황만 펴 둔다.

| 접기 | 어떻게 |
|---|---|
| 왼쪽 레일 | 브랜드 옆 단추 · `Ctrl+B` |
| 오른쪽 현황 | 서랍 머리 단추 · `Ctrl+J` |
| 아래 기록 | 기록 머리를 클릭 |

접힌 상태는 저장돼서 창을 다시 열면 그대로다.

---

## 새로 돌리기

### 강의 고르기

`재료\` 안의 폴더를 읽어 타일로 깐다. **카드**(3열)와 **촘촘히**(12열) 두 모드가 있다.
120강대가 쌓이면 촘촘히가 한 화면에 들어온다.

타일에는 **번호만** 뜬다. 자세한 내역은 **제목 옆 한 자리**에 뜨고, 타일에 마우스만
올려도 바뀐다 — 클릭하지 않고 훑을 수 있다.

점 색이 상태다.

| 점 | 뜻 |
|---|---|
| 초록 | 영상과 슬라이드가 다 있다 |
| 노랑 | 영상은 있고 슬라이드가 없다 — 그대로 돌아간다(씬 매핑만 건너뛴다) |
| 빨강 | mp4가 없다 — 고를 수 없다 |

### 설정

| 고르는 것 | 뜻 |
|---|---|
| 음성 언어 | 영상에서 **들리는** 말. 전사할 언어다 |
| 자막 언어 | 화면에 **뜨는** 글자 |
| 음성인식 모델 | `small` 빠름 / `medium` 정확하고 오래 |

아래 노란 띠가 고른 값을 문장으로 다시 읽어 준다. 둘이 다르면 번역 단계(s3b)가
끼어들고, 같으면 건너뛴다.

**번역이 필요한데 Claude 연결이 없으면** 그 문장 끝에 빨간 경고가 붙는다.
돌리기 전에 알 수 있다.

### 돌리기

단계 뱃지가 초록으로 넘어가고 아래 기록에 실시간으로 흐른다.
기록을 접어 두어도 머리에 마지막 줄이 뜬다.

## 자막 다듬기

큐를 한 줄씩 고친다. **타임코드는 건드리지 않는다** — 본문만 고치는 화면이다.

오른쪽 숫자가 글자 수고, 한도를 넘긴 줄은 **노랗게** 뜬다. 위 오른쪽에
`큐 N개 · 한 줄 최대 N자 · 넘긴 줄 N개` 가 실시간으로 바뀐다.

저장한 뒤 **`s6`부터** 다시 돌리면 반영된다.

## 컷 옮기기

조각의 시작·끝 초를 고친다. 막대가 길이를 보여 준다.

| 막대 | 뜻 |
|---|---|

저장한 뒤 `s6`부터 다시 돌린다.

## 왼쪽 아래 — Claude 연결

**자막 번역에만 쓰인다.** s1~s7은 이것 없이도 다 돈다. 그래서 메뉴가 아니라 맨 아래다.

누르면 실행 파일·로그인·파이썬 붙임 세 줄과 계정이 보이고,
`다시 확인` · `로그인` · `다른 계정으로` · `로그아웃` 단추가 있다.

로그인은 **콘솔 창**에서 한다 — 웹 화면이 대신 할 수 없다.
OAuth는 브라우저와 CLI가 주고받는 것이라 중간에서 토큰을 만지면 안 된다.
창에서 마친 뒤 `다시 확인` 을 누른다.
