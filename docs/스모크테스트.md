# 스모크 테스트 — whisper·piper 없이 로직만 검증

45분짜리 가짜 워크스페이스(무음 오디오 + 지어낸 단어 타임스탬프)를 만들어
s3 → s4 → s6 → check 를 돌린다. 모델을 안 받아도 되니 몇 초면 끝난다.
코드를 고친 뒤 회귀 확인용으로 쓴다.

```
.venv\Scripts\python docs\_smoke.py
.venv\Scripts\python scripts\s3_cue.py --lang ru
.venv\Scripts\python scripts\s4_split.py --lang ru
.venv\Scripts\python scripts\s6_package.py --sub-lang ru
.venv\Scripts\python scripts\check.py --sub-lang ru
```

`_smoke.py`는 1350초쯤에 **일부러 긴 침묵 하나**를 심는다. s4가 45분을 22분 30초
목표로 나누면서 그 침묵을 찾아내는지가 핵심 확인 항목이다.

마지막 항목은 **합치면 42자를 넘는 짧은 문장**들이다. 더 합치면 한 줄 규칙이
깨지므로 여기서 멈춘다. 실패가 아니라 주의로 둔 이유가 그것이다.

처음 돌렸을 때는 이게 200개(17.7%)였다. 문장을 앞에서부터 최대 글자수까지 꽉
채워 자르다 보니 문장 끝에 한두 단어짜리 꼬리가 남고, 그게 0.5초 스쳤다
사라졌다. `cues.py`의 `_break_into`가 **조각 수를 먼저 정하고 길이를 고르게
나누도록** 바꿔서 잡았다 — 50자 문장이 42+8이 아니라 25+25가 된다.
