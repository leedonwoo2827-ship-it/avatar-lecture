# 자막과 언어

## 기본은 음성 러시아어 + 자막 우즈벡어

이유는 정치가 아니라 **기술이다.** 이 파이프라인은 Whisper가 준 단어 타임스탬프
위에 자막 큐와 조각 분할점을 전부 얹는다. 그 타임스탬프가 흔들리면 뒷단이 통째로
흔들린다. 그리고 Whisper는 러시아어가 최상위권, 우즈벡어가 바닥권이다.

| | 음성 러시아어 + 자막 우즈벡어 | 음성 우즈벡어 + 자막 러시아어 |
|---|---|---|
| STT 타임코드 품질 | 높음 — 자동화된다 | 낮음 — 사람이 다 찍어야 한다 |
| 기존 데모 자산 | 그대로 이어감 | 재제작 |
| 아바타 립싱크 | 러시아어 음소, 안정적 | 검증 필요 |
| 현지 수용성 | 전문용어가 러시아어로 통용되는 분야에 유리 · 자막으로 접근성 확보 | 젊은 층에 유리하나 용어 혼선 |

**최종 결정은 프로젝트마다 다르므로 코드에 박아 두지 않았다.**
`--lang`(음성) / `--sub-lang`(자막)으로 바꾼다. 뒤집히면 플래그만 바꾸고, STT 결과를
사람이 더 손보는 시간을 예산에 얹으면 된다.

언어별 자막 한 줄 최대 글자수는 `scripts\common.py`의 `CUE_MAX_CHARS`에 있다 —
키릴 42 / 라틴 46 / 한글 30. 글자폭이 달라서 하나로 둘 수 없다.

## 우즈벡어 자막 만들기

### 이렇게 하면 안 된다

대본 단계에서 만든 우즈벡어 SRT를 그대로 쓰는 것. 그 타임코드는 대본의 **추정**
길이(`est_sec`) 기준이라 실제 음성과 어긋난다. 2026-08-26 실측으로 45분(2700초)으로
추정한 대본이 Piper로 읽으니 35.6분(2137초)이 나왔다. **10분이 밀린다.**

### 이렇게 한다

전사해서 얻은 러시아어 자막의 **타임코드를 그대로 쓰고 본문만 갈아끼운다.**
`s3b_relabel.py`가 그 일만 한다.

```
.venv\Scripts\python scripts\s3b_relabel.py --export --from ru
REM  → 03\번역할것.ru.txt   한 줄이 자막 하나다
```

이 txt를 SME·외주·번역기에 넘긴다. **줄 수를 바꾸지 말라고 못박는다** — 줄 하나가
자막 하나라 늘거나 줄면 전부 밀린다.

```
.venv\Scripts\python scripts\s3b_relabel.py --import "...\번역한것.uz.txt" --to uz
REM  → 03\subs.uz.srt   타임코드는 subs.ru.srt 과 완전히 동일

.venv\Scripts\python scripts\s6_package.py --sub-lang uz
```

들여올 때 **줄 수가 다르면 그 자리에서 멈춘다.** 최대 글자수를 넘는 줄도 몇 번째인지
찍어 준다. 번역 자체는 SME·외주 소관이고, 이 도구는 타임코드를 지켜 주는 일만 한다.

## 사람이 손대는 자리 — 딱 세 군데

| 파일 | 언제 |
|---|---|
| `03\subs.<lang>.srt` | 자막 문구를 다듬을 때 (SME 컨펌 반영) |
| `04\chunks.json` | 컷이 어색할 때 — 초 단위로 고친다 |
| `05\scenes.json` | 슬라이드 매핑이 틀렸을 때 |

**고친 파일이 이긴다.** s4·s6은 `cues.json`이 아니라 손편집 가능성이 있는 SRT를
다시 읽는다. 고친 뒤 그 다음 단계부터 다시 돌리면 그대로 반영된다.

나머지는 `check.py`가 기계로 본다 — 자막 글자수·한 줄 여부·겹침, 조각 길이가 perso
한계 안인지, 컷이 말 중간에 떨어지지 않았는지. 사람은 **컷 앞뒤 2초를 직접 들어
보는 것**과 **`scenes.csv` 표본 확인**만 하면 된다.

## 자막 모양

검수본에 굽는 자막의 글꼴·크기·위치는 `scripts\s7_preview.py`의 `STYLE` 한 줄이다.
perso에 올라가는 것은 자막이 구워지지 않은 클린본이라, 최종 화면의 자막 모양은
perso 쪽 설정이다.
