# Claude Code 데스크탑에 붙여넣을 지시문

파이프라인에 먹일 재료를 만드는 지시문이다. **내용 품질은 아무래도 좋다** — 배포물이
아니라 파이프라인 인풋용 더미다. 오직 규격(45분 · 자막 한 줄 · 1920×1080)만 맞으면 된다.

45분 통짜여야 하는 이유가 있다. perso 30분 한계에 실제로 걸려야 분할 로직(s4)이
검증된다. 30분짜리로 만들면 그냥 통과해 버린다.

만든 폴더는 `재료\` 안에 넣는다. 폴더 이름은 `NNN강`으로 시작하게 짓는다.

> `[대괄호]` 안은 프로젝트에 맞게 채운다. 실제로 쓴 예는 `_doc/` 에 있다(비공개).

---

[분야] 교육과정의 강의 1개 분량 샘플 재료를 만들어줘.
아바타 영상 제작 파이프라인의 입력 규격을 검증하기 위한 샘플이다.

## 강의 사양
- 주제: [강의 주제]
- 대상: [수강 대상 — 예: 현직 실무자, 디지털 도구 초급]
- **분량: 정확히 45분(2700초)** — 이건 반드시 맞춰라. 슬라이드 장수는 내용 흐름에
  맞게 네가 알아서 정해라(한 장에 60~120초 사이면 된다). 억지로 장수를 맞추느라
  내용을 늘리거나 줄이지 마라.
- 언어: 대본은 **[음성 언어]**, 자막은 **[자막 언어]**. 검수용으로 **한국어 대역**을
  나란히 둔다 (한국어는 최종본에서 빠진다).

## 만들어야 할 것 — 아래 3개, 폴더 하나에

### 1. `script.json` — 씬 단위 대본

    [
      {
        "no": 1,
        "slide_title_ru": "슬라이드 제목(음성 언어)",
        "slide_title_ko": "슬라이드 제목(한국어 대역)",
        "narration_ru": "이 슬라이드에서 말할 내레이션 전문(음성 언어)",
        "narration_ko": "같은 내용 한국어 대역",
        "est_sec": 82
      }
    ]

- `narration_ru`는 **사람이 소리 내어 읽는 문장**이다. 목록·불릿·기호·괄호주석 금지,
  완성된 구어체 문장으로만 쓴다. TTS에 그대로 먹일 거라 읽을 수 없는 기호가 있으면 안 된다.
- 숫자는 **글자로 풀어 쓴다**. 약어도 풀어 쓴다.
- 문장 끝에는 마침표를 반드시 찍는다 — 합성기가 문장 단위로 끊어 읽고, 그 사이의
  뜸이 나중에 영상을 자를 자리가 된다.
- `est_sec` 합계 = **2700초**. 마지막에 합을 직접 계산해서 확인하고, 맞을 때까지 조정해라.
- 45분은 길다. 도입 → 개념 → 실습 절차 → 사례 → 정리로 흐름을 잡고, 중간에
  "지금까지 정리하면" 같은 되짚는 대목을 두 번쯤 넣어라.

### 2. `subs.<자막언어>.srt` — 자막
- `script.json`의 `narration_ru`를 **[자막 언어]**로 옮긴 자막.
- ★ 가장 중요한 규칙: **큐 하나는 반드시 한 줄이다.** 큐 안에 줄바꿈을 넣지 마라.
- 큐 하나 최대 **46자**(라틴 문자 기준. 키릴이면 42자, 한글이면 30자).
  문장이 길면 쉼표·접속사 경계에서 자연스럽게 끊는다. 단어 중간에서 자르지 마라.
- 큐 하나 최소 노출 1.2초, 최대 6.0초. 큐끼리 시간이 겹치면 안 된다.
- 타임코드는 `est_sec` 누적으로 대략 잡아라 (실제 값은 나중에 STT가 다시 잡는다).

### 3. `slides/001.html`, `002.html`, … — 슬라이드
- 한 장이 파일 하나. `script.json`의 `no`와 파일 번호를 맞춘다.
- **1920×1080 고정**, 스크롤 없음.
- 제목 + 항목 3~5개, 그 이상 채우지 마라 (읽히는 게 목적이다).
- 인라인 CSS만. 외부 폰트·이미지·스크립트 금지 (오프라인에서 그대로 열려야 한다).
- 키릴 등 비라틴 문자가 깨지지 않게 `font-family`에 시스템 산세리프 폴백을 넉넉히 준다
  (`Arial`, `Segoe UI` 같은 것).
- 배경 밝게, 글자 어둡게 — **아래 20%는 자막 자리이니 비워 둔다.**

## 지키지 말아야 할 것
- **내용을 다듬느라 시간 쓰지 마라.** 파이프라인 검증용 더미다. 규격만 맞으면 된다.
- 다만 전문 분야의 사실관계를 **확정적으로** 지어내지는 마라. 확신 없으면 일반론으로 쓰고
  `[확인필요]`를 달아라 — 나중에 실제 콘텐츠로 갈아끼울 때 어디를 갈아야 할지 표시가 된다.
- 슬라이드에 로고·기관명·인물 사진을 넣지 마라.
- 파일 3종만 만든다. README나 요약 문서를 추가로 만들지 마라.

## 다 만든 뒤 스스로 확인할 것 (결과에 한 줄로 보고)
- `est_sec` 합계가 2700초인가
- 자막 SRT에 줄바꿈이 든 큐가 0개인가 / 최대 글자수를 넘는 큐가 0개인가 / 겹치는 큐가 0개인가
- 슬라이드 HTML 개수 = `script.json` 항목 수인가
