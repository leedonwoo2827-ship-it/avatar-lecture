# recmaker2perso-bridge

**강의 mp4 하나를 넣으면, 아바타 서비스에 그대로 올릴 조각 패키지가 나옵니다.**

영상을 만들지는 않습니다 — 만드는 건 아바타 서비스가 합니다. 이 저장소는 그 앞에서
**영상을 재료로 분해해 넘깁니다.**

```
            들어가는 것                        나오는 것
   ┌──────────────────────┐        ┌────────────────────────────┐
   │  강의 MP4             │        │  번들 2개                   │
   │  번역 자막 SRT (선택)  │   →    │   · 무음 MP4                │
   │  슬라이드 이미지 (선택) │        │   · 음성 파일 (립싱크 소스)   │
   └──────────────────────┘        │   · 한 줄 자막 SRT           │
                                   │   · 슬라이드 전환 시각표      │
                                   │   · 작업 지시서              │
                                   └────────────────────────────┘
```

## 왜 나누나

아바타 서비스가 **30분에서 끊깁니다.** 45분 강의는 잘라 넣어야 하는데,
초를 재서 자르면 말 한가운데가 끊겨 입모양이 깨집니다.
**말과 말 사이 가장 조용한 자리**를 찾아 끊습니다.

자막은 영상에 굽지 않습니다. SRT로 따로 넘깁니다 — 씬마다 자막 이미지를 만들어 얹던
작업이 이 한 가지 결정으로 없어집니다.

## 설치

```
setup.bat
```

Python 3.10+ 와 ffmpeg 가 있어야 합니다. 시험용 강의를 직접 만들 거라면
`tools\sample\setup.bat` 도 한 번 돌립니다.

## 쓰기

```
run.bat
```

브라우저가 열립니다. 이 창은 켜 둔 채로 씁니다.

`재료\` 안에 강의 폴더를 만들고 그 안에 mp4를 넣으면 화면 목록에 뜹니다.
슬라이드가 있으면 `slides\` 에 같이 넣습니다 — 없어도 돕니다.

| 화면 | 무엇 |
|---|---|
| 새로 돌리기 | 강의를 골라 s1~s7 |
| 자막 다듬기 | 큐를 한 줄씩. 타임코드는 안 건드립니다 |
| 컷 옮기기 | 조각 시작·끝 초 |
| 결과 | 넘길 폴더 열기 |

한 단계만 다시 돌릴 때는 스크립트를 직접 부릅니다.

```
.venv\Scripts\python scripts\s2_transcribe.py --lang ko --model small
```

## 나오는 자리

```
output\<작업>\
  01\  아바타용 음성 · 전사용 음성
  02\  단어 타임스탬프
  03\  한 줄 자막
  04\  조각 분할점
  05\  화면 전환 시각 ↔ 슬라이드
  06\  perso\chunk01\ …   ← 이것만 밖으로 나갑니다
       _preview\           검수용. 자막이 구워져 있어 올리지 않습니다
```

`03`·`04`·`05` 는 **사람이 손으로 고쳐도 됩니다.** 고친 파일이 이깁니다.

## 언어

음성 언어와 자막 언어를 따로 고릅니다. 둘이 다르면 번역 단계가 끼어들어
**전사에서 나온 타임코드를 그대로 두고 본문만 갈아끼웁니다.**

기본값은 `config.local.json` 에서 읽습니다(저장소에 없습니다).

```json
{ "audio_lang": "ko", "sub_lang": "en", "tts_voice": "en_US-lessac-medium" }
```

번역은 `claude` CLI 로 로그인해 둔 세션을 씁니다 — **API 키가 필요 없습니다.**
왼쪽 아래 단추에서 연결 상태를 봅니다.

## 무엇이 무슨 일을 하나

전부 **로컬**에서 돕니다. 강의 내용이 밖으로 나가지 않습니다.

| 단계 | 엔진 |
|---|---|
| 전사 | faster-whisper (small / medium) |
| 오디오 자르기 · 장면 검출 · 자막 번인 | ffmpeg |
| 자막 묶기 · 분할 · 검사 | 규칙 코드 (모델 없음) |
| 자막 번역 (선택) | Claude — 쓸 때만 돕니다 |

시험용 강의를 만들 때만 Piper(로컬 TTS)와 Chromium(슬라이드 굽기)을 씁니다.

## 검사

돌리기가 끝나면 검사표가 나옵니다. 자막 글자 수·한 줄 여부·겹침, 조각 길이,
컷이 말 중간에 떨어지지 않았는지를 기계가 전부 봅니다.
실패가 있으면 종료 코드 1로 끝나므로 배치에서 그 코드로 거를 수 있습니다.

사람이 볼 것은 둘입니다 — **컷 앞뒤 2초를 들어 보기**, **전환 시각표 표본 확인**.
