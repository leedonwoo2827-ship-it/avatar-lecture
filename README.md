# mp42perso

**강의 mp4 하나를 넣으면, perso 아바타에 그대로 올릴 조각 패키지가 나온다.**

대규모 강의 시리즈를 아바타 영상으로 만드는 공정에서, 이 저장소가 맡는 자리는
딱 한 토막이다.

```
compose + recmaker  →  45분 × 120강 초안
  → 우즈벡 SME 컨펌·수정
    → 외주업체 수정
      → [ 이 저장소 ]  mp4 → perso 투입 패키지
        → perso 아바타 (외주 추가지시)
```

## 영상을 만드는 도구가 아니다 — 분해하는 도구다

perso가 영상을 만든다. 이 저장소는 그 앞에서 **영상을 재료로 분해해 넘긴다.**

```
              들어가는 것                    나오는 것
        ┌──────────────────┐          ┌──────────────────────┐
        │  강의.mp4  45분   │   →      │  chunk01\  약 22분    │
        │  슬라이드 이미지   │          │  chunk02\  약 22분    │
        └──────────────────┘          └──────────────────────┘
                                       각 폴더 안에
                                         audio.m4a      아바타 음성 소스
                                         subs.ru.srt    자막 트랙
                                         scenes.csv     슬라이드 넘길 시각
                                         slides\        화면 소스
                                         지시서.md       외주 작업 지시
```

45분을 두 조각으로 나누는 이유는 **perso가 30분에서 끊기기** 때문이다. 그렇다고 초를
재서 자르지 않는다 — 말 한가운데가 잘리면 아바타 입모양이 그 자리에서 깨진다.
말과 말 사이 **가장 조용한 자리**를 찾아 끊는다.

자막은 영상에 굽지 않는다. SRT 파일로 따로 넘긴다. 씬마다 자막 이미지를 만들어 얹던
수작업이 이 한 가지 결정으로 통째로 없어진다.

## 아웃풋이 정확히 어디에 나오나

강의 하나가 폴더 하나다. 폴더 이름 앞자리가 만든 시각이라 정렬하면 시간 순서가 된다.

```
output\2608262138-강의이름\
  00\  원본 mp4 · slides\          넣은 것을 그대로 보관
  01\  audio.m4a                  아바타 립싱크 소스 (원본 품질, 자막 없음)
       stt.wav                     전사 전용 16kHz mono
  02\  words.json                  단어 하나하나의 시각 ← 뒷단 전부의 바탕
  03\  subs.ru.srt                 한 줄 자막
  04\  chunks.json                 어디서 잘랐는지
  05\  scenes.csv                  화면이 바뀌는 시각 ↔ 슬라이드
  06\  perso\chunk01\  chunk02\    ★ perso에 올리는 것. 이것만 넘긴다
       _preview\                    검수용 자막 번인본 — perso에 올리지 않는다
```

**`06\perso\` 만 밖으로 나간다.** `00`~`05`는 중간산물이고, 문제가 생겼을 때 어디서
틀어졌는지 되짚기 위해 남겨 둔다.

## 무슨 모델이 무슨 일을 하나

전부 **로컬 CPU**에서 돈다. API 키가 필요 없고, 강의 내용이 외부로 나가지 않는다.

| 단계 | 엔진 / 모델 | 하는 일 |
|---|---|---|
| `s2_transcribe` | **faster-whisper** (`small` 500MB / `medium` 1.5GB) | 러시아어 음성 → **단어 하나하나의 시각**. 자막과 컷이 전부 이 위에 얹힌다 |
| `s1` `s4` `s6` | **ffmpeg** | 오디오 추출·정확한 초 단위 자르기 |
| `s5_scene_map` | **ffmpeg** 장면 검출 | 화면이 바뀌는 순간 찾기 (슬라이드 전환) |
| `s7_preview` | **ffmpeg** `subtitles` 필터 | 검수용 자막 번인 — 자막 이미지를 만들지 않는다 |
| `s3` `s4` `s6` `check` | 모델 없음 (규칙 코드) | 자막 묶기·분할·패키지·검사 |
| `s3b --translate` | **Claude** (`claude` CLI 로그인, API 키 없음) | 자막 초벌 번역 — 이것만 유료이고 **쓸 때만** 돈다 |

**s1~s7 은 LLM을 부르지 않는다.** 120강을 돌려도 API 비용이 0이다.
(자막 번역만 예외이고, 그건 부르고 싶을 때만 따로 돈다.)
(슬라이드 매핑도 LLM이 아니라 ffmpeg 장면 검출로 한다 — 이유는
[설계와-앞으로](docs/설계와-앞으로.md#슬라이드-매핑에-llm을-쓰지-않는-이유))

LLM·TTS는 **시험용 강의를 만들 때만** 쓰인다. 본편에는 관여하지 않는다.

| 단계 | 엔진 / 모델 | 하는 일 |
|---|---|---|
| 재료 만들기 | **Claude Code 데스크탑** | 대본·자막·슬라이드 HTML 초안 (파이프라인 밖) |
| `t1_tts` | **Piper** `ru_RU-irina-medium` (ONNX, MIT) | 대본 → 러시아어 음성. 슈퍼토닉-3는 한국어 전용이라 못 쓴다 |
| `t2_slides_png` | **Chromium** (Playwright) | 슬라이드 HTML → 1920×1080 PNG |
| `t3_mux` | **ffmpeg** | 음성 + 슬라이드 → 45분 dummy.mp4 |

## 설치 — 처음 한 번

```
setup.bat                    REM python·ffmpeg 확인 + .venv + 패키지
tools\sample\setup.bat       REM (선택) 시험용 강의를 만들 때만
```

`setup.bat`이 먼저다. `s2`를 처음 돌릴 때 음성인식 모델을 한 번 내려받는다
(small 약 500MB / medium 약 1.5GB).

## 쓰기

```
run.bat                      REM http://127.0.0.1:6326 이 자동으로 열립니다
```

이 창은 켜 둔 채로 씁니다 — 닫으면 서버가 꺼집니다.

| 화면 | 무엇 |
|---|---|
| 새로 돌리기 | `재료\` 폴더를 골라 s1~s7. 진행이 단계 뱃지로, 기록이 아래 도크에 흐릅니다 |
| 자막 다듬기 | 큐를 한 줄씩 고칩니다. 타임코드는 안 건드립니다. 글자 수 넘긴 줄은 노랗게 |
| 컷 옮기기 | 조각 시작·끝 초를 고칩니다. 28분 넘으면 막대가 빨갛게 |
| 결과 | 조각 목록 + `perso에 올릴 폴더`·`검수용 영상` 열기 |

왼쪽 레일(`Ctrl+B`) · 오른쪽 현황 서랍(`Ctrl+J`) · 아래 기록 도크가 **따로** 접힙니다.
강의 고르기는 **카드**(3열)와 **촘촘히**(10열, 120강이 한 화면) 두 모드가 있습니다.

perso 업로드·아바타 선택은 넣지 않았습니다 — 스펙 확인 전이라 지금 만들면 절반은
버립니다. 자세한 것은 [docs/설계와-앞으로.md](docs/설계와-앞으로.md).

### 명령줄로 단계별 돌리기

한 단계만 다시 돌리거나 배치로 돌릴 때 씁니다.

| 단계 | 하는 일 |
|---|---|
| `s1_ingest.py` | 번들 폴더(또는 mp4) → 아바타용 오디오 + 전사용 오디오, 슬라이드 정리 |
| `s2_transcribe.py` | 전사 → 단어 타임스탬프 |
| `s3_cue.py` | 단어 타임스탬프 → **한 줄** 자막 |
| `s3b_relabel.py` | (선택) 타임코드 유지하고 자막 본문만 다른 언어로 |
| `s4_split.py` | perso 30분 한계에 맞춰 자를 자리 찾기 |
| `s5_scene_map.py` | 화면이 바뀌는 순간 ↔ 슬라이드 |
| `s6_package.py` | `06\perso\chunkNN\` 만들기 |
| `s7_preview.py` | (선택) 검수용 자막 번인본 |
| `check.py` | 규칙을 어겼는지 기계로 전부 확인 |

```
.venv\Scripts\python scripts\s1_ingest.py "재료강-EMR기초"
.venv\Scripts\python scripts\s2_transcribe.py --lang ru --model small
```

`s1_ingest.py`에 폴더를 주면 안에서 영상·슬라이드를 알아서 찾습니다. 무엇을 찾았는지만
보려면 `--dry-run`을 붙입니다.

## 시험용 강의를 만들려면

실제 강의가 오기 전에 파이프라인을 돌려 보려면 `tools\sample\`이 45분짜리 가짜 강의를
만들어 준다. 대본·슬라이드는 Claude Code 데스크탑에 만들게 하고
([지시문](docs/재료-지시문.md)), 음성은 Piper 러시아어로 합성한다.

```
tools\sample\run.bat "재료\강의폴더"
REM  → 재료\강의폴더\dummy.mp4
```
